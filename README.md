# 내 대시보드

엣지 시작 페이지로 쓰는 미니멀 개인 대시보드입니다. 즐겨찾기, 검색, 시계, 날씨, 미세먼지, 디데이, 코스피·나스닥 지수를 보여주고 GitHub 비공개 저장소를 통해 PC, 노트북, 태블릿이 같은 데이터를 씁니다.

## 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 화면 |
| `style.css` | 디자인 (라이트/다크 자동) |
| `app.js` | 즐겨찾기 관리, 검색, GitHub 동기화 |
| `sw.js`, `manifest.webmanifest`, `icon.svg` | 오프라인 실행, 태블릿 홈 화면 추가 |
| `scripts/fetch-market.mjs` | 코스피·나스닥 지수를 받아 `market.json` 생성 |
| `.github/workflows/deploy.yml` | GitHub Pages 배포 + 장중 10분마다 지수 갱신 |
| `serve.js` | 내 PC에서 미리 보기용 (배포에는 불필요) |

## 사용법

- **편집**: 오른쪽 아래 연필 버튼 또는 `E` 키
  - 타일 클릭 → 수정, × → 삭제 (되돌리기 가능), 끌어서 순서 변경
  - 타일을 다른 그룹 탭 위에 놓으면 그 그룹으로 이동
  - 선택된 그룹 탭을 다시 누르면 이름 변경/삭제, `+` 탭으로 그룹 추가
- **검색**: `/` 키로 검색창 이동. 입력하면 즐겨찾기를 먼저 찾아주고, Enter를 누르면 웹 검색 (주소를 입력하면 바로 이동)
- **설정**: 오른쪽 아래 슬라이더 버튼 → 새 탭 열기, GitHub 동기화, JSON 백업

## GitHub에 올리고 동기화하기

### 1. 저장소 두 개 만들기
1. **`dashboard`** (Public): 이 폴더의 파일을 올립니다. 개인 데이터는 들어가지 않습니다.
2. **`dashboard-data`** (**Private**): 만들 때 *Add a README file*을 체크합니다. 즐겨찾기가 저장되는 곳입니다.

### 2. 화면 올리기 (GitHub Pages)
1. `dashboard` 저장소에 이 폴더의 파일을 `.github` 폴더까지 포함해 올립니다. 숨김 폴더라 웹 업로드에서 빠지기 쉬우니 git으로 올리는 것을 권장합니다.
2. 저장소 *Settings → Pages → Build and deployment → Source*를 **GitHub Actions**로 바꿉니다.
3. *Actions* 탭에서 `deploy`가 끝나면 `https://<사용자명>.github.io/dashboard/` 주소로 접속됩니다. 바로 배포하려면 *Actions → deploy → Run workflow*를 누릅니다.

### 3. 토큰 만들기 (데이터 저장소 전용)
1. GitHub 오른쪽 위 프로필 → *Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token*
2. *Repository access*: **Only select repositories** → `dashboard-data`만 선택
3. *Permissions → Repository permissions → Contents*: **Read and write**
4. 만료 기간을 정하고 생성한 뒤 토큰을 복사합니다. 만료되면 새로 만들어 다시 입력하면 됩니다.

> 이 토큰은 `dashboard-data` 저장소의 파일만 읽고 쓸 수 있습니다. 각 기기의 브라우저에만 저장되고 코드나 저장소에는 들어가지 않습니다.

### 4. 대시보드에서 연결
설정 → GitHub 동기화에 사용자명, 저장소(`dashboard-data`), 토큰을 입력하고 **연결**을 누릅니다. 다른 기기에서도 같은 주소로 접속해 한 번만 연결하면 됩니다.

## 엣지 시작 페이지로 지정
- 엣지 *설정 → 시작, 홈 및 새 탭 → Microsoft Edge가 시작될 때 → 다음 페이지 열기*에서 대시보드 주소 추가
- 같은 화면의 *홈 단추*도 대시보드 주소로 지정하면 홈 버튼으로 바로 이동
- 참고: 엣지의 "새 탭" 페이지 자체를 바꾸려면 확장 프로그램이 필요합니다.

## 태블릿
엣지(또는 사파리/크롬)로 주소에 접속 → 메뉴(공유) → **홈 화면에 추가**하면 앱처럼 열립니다.

## 동기화 동작 방식
- 변경하면 즉시 이 기기에 저장되고, 약 1초 뒤 GitHub에 올라갑니다.
- 다른 기기에서 바꾼 내용은 대시보드 화면으로 돌아올 때 자동으로 불러옵니다.
- 인터넷이 끊겨도 마지막 데이터로 동작하고, 다시 연결되면 저장됩니다.
- 두 기기에서 동시에 수정하면 나중에 저장한 쪽이 남습니다. 이전 내용은 `dashboard-data` 저장소의 커밋 기록에서 복구할 수 있습니다.

## 시계
- 설정 → 시계에서 모양을 고를 수 있습니다. 미리 보기를 보고 누르면 바로 바뀝니다.

| 모양 | 설명 |
|---|---|
| 기본 | 얇은 숫자 |
| 굵게 | 두꺼운 숫자 |
| 플립 | 숫자 카드가 위에서 아래로 넘어가는 탁상 시계 |
| 디지털 | 7세그먼트 LED |
| 아날로그 | 바늘 시계 |

- "초 표시"와 "12시간제(오전/오후)"를 따로 켤 수 있습니다. 아날로그는 12시간제 설정이 필요 없어 비활성화됩니다.
- 플립의 넘어가는 동작은 Windows의 "애니메이션 효과" 설정을 꺼 둔 기기에서도 그대로 보입니다.

## 날씨
- 날짜 옆에 현재 기온, 최고/최저, 지역이 표시됩니다. 마우스를 올리면 체감온도와 강수확률이 보이고, 누르면 네이버 날씨로 이동합니다.
- 기본 위치는 서울입니다. 설정 → 날씨에서 도시를 검색해 바꾸거나 **현재 위치 사용**을 고를 수 있습니다.
- 현재 위치를 고르면 기기마다 그 기기의 위치를 씁니다. 처음에 브라우저가 위치 권한을 묻습니다.
- 지역 검색은 Open-Meteo(큰 도시·해외 도시)와 OpenStreetMap(국내 시·군·구·동)을 함께 찾아 합칩니다. "강남"처럼 같은 이름이 많은 곳은 "강남구"처럼 정식 이름으로 검색하세요.
- 데이터는 [Open-Meteo](https://open-meteo.com)(무료, 키 없음)에서 받고 15분마다 갱신합니다. 좌표는 약 1km 단위로 반올림해서 보냅니다.

## 미세먼지
- 날씨 옆에 `미세 좋음 · 초미세 보통`처럼 표시됩니다. 등급은 환경부 기준이고, 색은 좋음(파랑)·보통(초록)·나쁨(주황)·매우나쁨(빨강)입니다.
- 마우스를 올리면 수치(㎍/㎥)가 보이고, 누르면 네이버 미세먼지로 이동합니다.
- 날씨와 같은 위치, 같은 Open-Meteo에서 받습니다. 측정소 실측값이 아니라 **예보 모델 추정값**이라 에어코리아 수치와 조금 다를 수 있습니다.
- 설정 → 날씨 → "미세먼지 표시"로 끌 수 있습니다.

## 디데이
- 설정 → 디데이에서 이름과 날짜를 넣어 추가하고, ×로 삭제합니다 (바로 아래 "되돌리기" 가능).
- 날짜 아래에 `시험 D-12`처럼 표시되고, 누르면 디데이 설정으로 바로 이동합니다.
- 다가오는 날이 가까운 순으로 먼저, 지난 날은 `D+3`처럼 흐리게 뒤에 나옵니다. 당일은 `D-Day`로 강조됩니다.
- 즐겨찾기와 함께 GitHub에 저장되어 모든 기기에서 같이 보입니다.

## Gmail
즐겨찾기 아래에 안 읽은 메일 수와 받은편지함의 안 읽은 최근 메일 5개(보낸 사람·제목·시간)가 나옵니다. Gmail 아이콘에도 빨간 숫자 배지가 붙습니다. 메일을 누르면 Gmail에서 그 대화가 열립니다.

- **본문은 읽지 않습니다.** 메일 정보만 보는 권한(`gmail.metadata`)만 요청합니다.
- **메일 내용은 저장하지 않습니다.** 브라우저 화면에만 보여주고 GitHub 동기화 파일에도 들어가지 않습니다. 로그인 토큰(1시간 유효)만 그 기기에 보관합니다.
- 5분마다 새로 확인합니다. 토큰이 만료되면 패널에 "다시 연결" 버튼이 나오고, 누르면 로그인 창이 잠깐 떴다 닫힙니다.

### Google Cloud 설정 (처음 한 번, 약 10분)
1. [Google Cloud 콘솔](https://console.cloud.google.com)에 Gmail 계정으로 로그인 → 위쪽 프로젝트 선택 → **새 프로젝트** (이름 예: `dashboard`) → 만들기
2. **API 및 서비스 → 라이브러리**에서 `Gmail API` 검색 → **사용**
3. **API 및 서비스 → OAuth 동의 화면**(Google Auth Platform)
   - 앱 이름(예: `내 대시보드`), 사용자 지원 이메일에 본인 메일 입력
   - 대상(User type): **외부**
   - **테스트 사용자**에 본인 Gmail 주소 추가 (여기 추가한 계정만 로그인 가능)
4. **클라이언트(사용자 인증 정보) → 클라이언트 만들기 → OAuth 클라이언트 ID**
   - 애플리케이션 유형: **웹 애플리케이션**
   - **승인된 JavaScript 원본**에 두 줄 추가:
     - `https://<GitHub 사용자명>.github.io`
     - `http://localhost:8096` (내 PC 미리 보기용)
   - 만들기 → 나온 **클라이언트 ID**(`….apps.googleusercontent.com`) 복사
5. 대시보드 **설정 → Gmail**에 클라이언트 ID를 붙여넣고 **연결**
   - 구글 창에 "Google에서 확인하지 않은 앱" 경고가 나옵니다. 내가 만든 앱이라 정상입니다. **고급 → (앱 이름)(으)로 이동 → 계속**을 누르고 메일 정보 보기 권한을 허용하세요.

> 클라이언트 ID는 비밀번호가 아니라 공개돼도 되는 값이라 동기화 데이터에 함께 저장되고, 다른 기기에서는 **연결** 버튼만 누르면 됩니다.
> 앱이 "테스트" 상태라 구글이 가끔(대략 일주일 간격) 다시 허용을 요청할 수 있습니다.

## 시장 지수 (코스피·나스닥)
- 증권 사이트는 브라우저에서 직접 데이터를 가져가는 것을 막아 둡니다. 그래서 GitHub Actions가 대신 받아 `market.json`으로 함께 배포합니다.
- 평일 장중에 10분마다 갱신됩니다 (코스피: 한국시간 09~16시, 나스닥: 22시~다음날 06시). GitHub 사정에 따라 몇 분 더 늦을 수 있어 **실시간 시세가 아닙니다**.
- 상승은 빨강, 하락은 파랑으로 표시합니다. 장중이면 초록 점이 깜빡입니다. 마우스를 올리면 기준 시각이 보이고, 누르면 네이버 증권 상세 페이지로 이동합니다.
- 데이터는 야후 파이낸스에서 받고, 실패하면 네이버 증권에서 받습니다. 둘 다 실패하면 이전 값을 흐리게 보여줍니다. 둘 다 공식 API가 아니라서 사이트가 바뀌면 멈출 수 있습니다.
- 지수를 더 넣으려면 `scripts/fetch-market.mjs`의 `INDICES`에 추가합니다. 끄려면 설정에서 "코스피·나스닥 지수 표시"를 해제합니다.
- GitHub은 저장소에 60일 동안 활동이 없으면 예약 실행을 멈춥니다. 멈추면 *Actions* 탭에서 다시 켜면 됩니다.
